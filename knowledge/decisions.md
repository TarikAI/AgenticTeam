# Reusable Decisions

Cross-build decision patterns promoted from per-run `runs/<run-id>/_decisions/ADR-NNN.md` records
(template: `.agentic-team/templates/adr.md`). Promote only decisions likely to recur (stack
combinations, provider choices, architecture patterns), and state the conditions under which each
holds. Sanitise first (checklist in `README.md`).
