# Agent Evolution Proposals

Level 3 of `protocols/evolution.md`: changes to **agent definition files** themselves.
Collected at retrospective by delivery-lead (engineering) and cmo (marketing), reviewed by
ceo, **approved only by the human owner**. Applied to the master repo, not just one project.

## Rules
- One proposal, one change. No omnibus rewrites.
- Every proposal cites evidence: lessons entries, playbook checks that kept firing, or a
  concrete defect. "I think it would read better" is not evidence.
- Guardrails may be **tightened** by proposal, never loosened. Loosening is a human edit.
- Include the exact replacement wording, so applying it is mechanical.

## Format

```
### P-001 · <agent-name>: <one-line change>
- evidence: <lessons refs / defect ids / how many times the playbook check fired>
- section: <which section of the agent file>
- change: <exact wording to add/replace>
- risk: <what this could make worse>
- status: proposed | approved | rejected | applied (YYYY-MM-DD)
```
