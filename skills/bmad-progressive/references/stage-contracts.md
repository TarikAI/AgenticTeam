# Stage contracts

Each `CONTEXT.md` contains:

1. **Purpose** — the decision or transformation this stage owns.
2. **Working inputs** — current run artifacts allowed to change.
3. **Stable references** — policies, code, research, standards, and their freshness.
4. **Process** — ordered actions and participating roles.
5. **Outputs** — exact artifact paths and owners.
6. **Human check** — `none` or checkpoint question and evidence.
7. **Exit criteria** — objective tests before progressing.
8. **Next load** — the smallest context needed by the following stage.

Readiness must trace user outcomes and non-functional requirements to architecture, tasks,
tests, owners, and unresolved risks. Story/task packets contain only what one implementer needs.
